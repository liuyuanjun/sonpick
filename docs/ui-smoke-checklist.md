# 前端 UI 冒烟清单（人工）

适用场景：任何触及**播放器外壳 / 布局 / 主题**的改动，发布 rc 之前走一遍。
最近一次大改：v0.15.1-rc12「侧边栏重组 + 全局大播放器抽屉 + 悬浮胶囊播放条」。

> 仓库 `tests/` 全部是后端 Python 测试，前端**没有任何自动回归网**。
> 本清单是目前唯一的前端质量门，改动涉及前端时不要跳过。

## A. 侧边栏与路由（桌面）

- [ ] 侧边栏分为「我的音乐」与「系统管理」两组，组标题可见、间距正常、无重叠。
- [ ] 六个音乐项（我喜欢的 / 歌单 / 艺术家 / 专辑 / 全部歌曲 / 最近播放）点击后**内容与高亮同步**。
- [ ] 直接访问 `/player/albums`，页面进入专辑网格且侧边栏「专辑」高亮。
- [ ] 访问 `/player`，地址栏自动变为 `/player/favorites`。
- [ ] 访问 `/player/不存在的值`，自动纠正为 `/player/favorites`，侧边栏不出现「全无高亮」。
- [ ] 在 `/player/songs` 与 `/player/artists` 之间连续点击浏览器**后退 / 前进**，列表与高亮每次都跟着变。
- [ ] 侧边栏折叠（收起为 64px）后，六个音乐项的图标仍可点、tooltip 正常。

## B. 悬浮胶囊播放条（桌面）

- [ ] 有歌曲播放时，底部出现悬浮胶囊：**宽度不超过 880px、居中、两端为完整半圆、离底边约 24px**。
- [ ] 两侧留白对称，1280px 与 1000px 视口下均不贴边、不抖动。
- [ ] 胶囊不遮挡内容：滚动到列表最后一行，最后一行能完整露出（预留高度生效）。
- [ ] 左区封面 + 标题/艺人正常；长标题**省略号截断**而不是撑破布局。
- [ ] 中区：上一曲 / 播放暂停 / 下一曲 / 队列 / 播放模式 / 无损优先 全部可点，时间轴可拖动。
- [ ] 右区：静音、音量滑条、展开、关闭 全部可用。
- [ ] 窗口从 1200px 缓慢拖到 900px：**音量滑条先消失**，中间进度条仍有可用宽度（不会缩成一条线）。
- [ ] 亮/暗两态下胶囊的磨砂、描边、阴影都可见，且**没有出现纯黑或纯白的硬色块**。

## C. 全局大播放器抽屉（桌面，重点）

- [ ] 点胶囊**封面/标题**或右侧**展开**按钮，抽屉从下向上滑入。
- [ ] 抽屉**只盖住 Header + 内容区，左侧系统侧边栏保持可见可点**（点侧边栏能直接跳到下载/设置）。
- [ ] 抽屉内黑胶旋转、歌词滚动、标签刮削、获取歌词、播放队列全部正常。
- [ ] **同一时刻只存在一份播放面板**：检查 DOM 中 `.player-panel` 数量为 1（Elements 面板搜索即可）。
- [ ] 点队列按钮：队列在抽屉右侧展开；再点收起。
- [ ] 抽屉左上角「收起」按钮（下箭头）可用，点击后抽屉滑出。
- [ ] 按 `Esc` 抽屉平滑收起，**焦点回到打开前的元素**。
- [ ] 打开抽屉后按 `Tab`：焦点在抽屉内部循环，**不会跑到侧边栏或底层列表**。
- [ ] 抽屉打开时滚动鼠标滚轮：底层列表**不滚动**（滚动锁生效）。
- [ ] 在抽屉内打开「刮削信息」弹窗，按 `Esc`：**只关弹窗，抽屉保持打开**；再按 `Esc` 才关抽屉。
- [ ] 离开 `/player` 页面（例如点侧边栏进「曲库」），抽屉**保持打开**（不再因离开播放器页被强制关闭）。

## D. 移动端（≤768px，DevTools 设备模式）

- [ ] 底部 5 个 Tab 正常；进入播放器页时「播放器」Tab **正确高亮**。
- [ ] 播放器页顶部出现**横向滚动的二级 Tab**（我喜欢的 / 歌单 / 艺术家 / 专辑 / 全部歌曲 / 最近播放），可横向滑动，点击切换生效。
- [ ] 二级 Tab 与底部 Tab **不是同一套**、互不遮挡；二级 Tab 不随内容滚动跑掉。
- [ ] 悬浮胶囊位于底部 Tab **之上**（不被压住、不重叠），并考虑 `safe-area-inset-bottom`。
- [ ] 点胶囊打开抽屉：抽屉为**全屏**，**底部 Tab 栏不会浮在抽屉之上**。
- [ ] 抽屉内点队列按钮：队列以**全屏覆盖**形式出现（不是 280px 的窄栏），点「关闭」能回到面板。
- [ ] 抽屉内滚动/上下滑动时，**背景页面不跟着滚动**（iOS Safari 实测滚穿透）。
- [ ] 长列表滚动到最底部，最后一行不被胶囊遮挡。

## E. 断点跨界

在 1280 / 1100 / 1040 / 900 / 769 / 768 / 375 宽度各看一眼：

- [ ] 胶囊在 769px ↔ 768px 切换时尺寸/位置平滑，不出现半截圆角或高度跳变。

## F. 动效与无障碍

- [ ] 系统开启「减少动态效果」（macOS：辅助功能 → 显示器 → 减少动态效果）后，抽屉与胶囊的滑入动画**被禁用**，黑胶**不再旋转**。
- [ ] 键盘可达：`Tab` 能走到胶囊的每一个按钮，焦点环可见。
- [ ] 抽屉有 `role="dialog"` 与 `aria-modal="true"`（Elements 面板核对）。
- [ ] 二级 Tab 为真实 `<button>`，当前项带 `aria-current="page"`。

## G. 主题一致性（呼应 AGENTS.md §5.4）

- [ ] 亮/暗两态下，抽屉与胶囊**没有任何写死的深色底**（历史问题：`#0b0c10` 硬编码导致明亮模式出现黑块）。
- [ ] 切换主题时抽屉保持打开，颜色即时跟随，不闪白。
- [ ] 全局搜索 `#0b0c10` / `#0B0C10` / `rgba(127,127,127` 在 `web/src` 下不应新增命中（`theme/tokens.js` 与登录页品牌栏除外）。

## I. 失败时怎么报

记录：**视口宽度 + 主题模式 + 具体页面 + 复现步骤 + 截图**，并按 P0/P1/P2 标注。
判断标准：

- **P0**：功能丢失、同一组件重复渲染、内容被遮挡、弹层被盖、移动端不可用。
- **P1**：断点处视觉跳变、间距/对齐错位、动效异常、焦点逃逸。
- **P2**：圆角/阴影/过度细节的像素级偏差。
